# Digital Hishab

**Digital Hishab** is a personal expense management application designed to help users manage, track, and understand their income, expenses, savings, and financial records in one place.

## Features

- 📊 Dashboard for financial overview
- 💰 Income and expense management
- 📅 Date-based transaction tracking
- 🗓️ Monthly financial records
- 💾 Savings and carried balance management
- 📈 Financial summaries and analysis
- 🧾 Monthly expense record export
- 🧮 Yearly tax calculator
- 💵 Monthly fixed-cost management
- 🌍 Nearby currency exchange information
- 💱 Preferred currency support
- 🎨 Light and dark theme modes
- 📤 Data export
- 🔐 User authentication
- 🌐 Responsive mobile-friendly interface

## Technology

- React
- TypeScript
- Vite
- Firebase Authentication
- Firebase Firestore
- CSS
